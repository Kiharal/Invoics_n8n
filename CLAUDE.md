# Project Context: Yakwetu Re-Engagement Engine

n8n + AI re-engagement engine demo for Yakwetu (www.yakwetu.africa), a Kenyan pay-once, own-forever film platform. Presentation Fri 2 Oct 2026. The demo is built; this week is fine-tuning.

Read first: `docs/decisions.md` (locked decisions D1 to D9, scope), `README.md` (how to run, demo script, deviations from the roadmap contracts).

## Stack
- n8n (Docker) runs all decisions: workflows are generated by `tools/build-workflows.js` into `/workflows`. Edit the generator, not the JSON, then re-import.
- Backend: Node/Express in `backend/` (no DB, in-memory state, reset via UI). Plays Yakwetu's platform, hosts the log store (SSE), delivery adapters and an offline AI stub.
- AI: Ollama (`qwen2.5:7b` default) via plain HTTP from n8n, JSON mode, temperature 0.2.
- Deploy: plain Docker Compose, ports bound to 127.0.0.1. `sh tools/setup.sh` (stub AI) or `sh tools/setup.sh --ai` (Ollama is behind the `ai` compose profile). n8n reaches the model via the backend proxy `/ai`, so the panel's stub switch works on the real stack.

## Rules that must not break
- Delays configured in REAL minutes; only `compress()` converts (D4). Same formula in n8n Branch config, the win-back scan and the panel.
- LLM only picks from rule-built candidates; guardrails reject unknown ids, >300 chars, urgency/discount/rent words; any failure sends the fallback template and logs why.
- Consent read fresh from the backend after the wait; purchase re-checked after the wait AND right before delivery (Final re-check node).
- AI lane personalisation comes from facts in the brief (profile, story, cast, why_for_viewer). The model may not invent facts; guardrails check it names the film, no other candidate, no example leak, real price only.
- WhatsApp marketing only when price_kes >= WHATSAPP_MIN_KES; utility (payment/device) messages carry no promotion.
- Every stage writes a log row; the panel is the evidence if a channel fails on stage.

## Testing
`node tools/harness.js` runs the pipeline JSON against the backend without n8n (set BACKEND_URL, OLLAMA_URL to the stub). Use it after every generator change.
`node tools/stress.js` (BACKEND_URL, WEBHOOK_URL) fires overlapping scenarios and checks the rules above against the log; works against the harness or real n8n. It resets backend state.
Windows Git Bash: use `MSYS_NO_PATHCONV=1` with `docker exec ... /workflows`, else import finds 0 workflows. Set it per command only: exported globally it breaks `curl -o /dev/null`.
Judge audit scripts live in `tools/stress/` (functional, load, chaos, hostile); results and gaps in `docs/stress-test-report.md`. Test scripts switch real email off (Mailtrap quota).
